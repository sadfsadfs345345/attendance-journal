📲 Скачать APK для Android
📖 Как установить:
1
Нажмите кнопку выше — APK скачается автоматически
2
Откройте файл из уведомления или папки «Загрузки»
3
Если появится предупреждение — нажмите «Разрешить» → «Установить»
4
Иконка «Журнал» появится на рабочем столе ✨
⚠️ Андроид может спросить разрешение для установки из неизвестных источников. Нажмите «Разрешить» — это безопасно, приложение разработано вами.
